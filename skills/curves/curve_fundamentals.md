# Fundamentos de curvas

Usa curvas 3D para trayectorias que deben seguir siendo editables. Bézier es la
opción preferida cuando la transición visual depende de handles; NURBS sirve
para trayectorias suaves con control global; Poly solo cuando se desean tramos
rectos deliberados. Inspecciona antes de editar y conserva al menos dos puntos.
