# Instrucciones específicas para Blender

- No guardar archivos `.blend`, copias de respaldo ni exportaciones dentro de `D:\Harness Blender`.
- No crear una copia del archivo de Blender antes de cada modificación.
- Priorizar modificadores, snapshots internos y operaciones reversibles para poder deshacer los cambios.
- Guardar el archivo solo cuando la persona lo solicite expresamente o indique una ruta concreta fuera de `D:\Harness Blender`.
- Antes de modificar, inspeccionar la escena y trabajar en cambios pequeños y localizados.
