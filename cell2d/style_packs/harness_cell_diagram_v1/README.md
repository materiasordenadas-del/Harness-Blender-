# Harness Cell Diagram v1

Este es el paquete visual objetivo de Cell2D. Sus assets pueden partir de bibliotecas abiertas con estilos distintos, pero las versiones Harness deben ser coherentes entre sí y respetar `cell2d/config/style.json`.

El manifiesto empieza vacío a propósito: no declara como existente ningún símbolo que aún no haya sido importado, adaptado y revisado en Blender.
