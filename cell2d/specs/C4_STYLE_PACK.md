# C4 — Style Pack Cell2D v1

## Objetivo

Convertir el contrato C0 en una biblioteca visual real y aprobada para Blender. El Style Pack define cómo se ve el resultado Harness; no modifica la identidad ni el comportamiento de los elementos celulares.

## Contenido mínimo

- Membrana y citoplasma.
- Núcleo, mitocondria y vesícula.
- Canal, bomba, transportador y receptor.
- Proteína de señalización, ion y segundo mensajero.
- Flecha de activación, transporte e inhibición.
- Etiqueta.

## Reglas de procedencia

- Cada asset se registra en el catálogo con fuente, licencia, atribución y hash.
- Un asset de referencia puede provenir de otro estilo; el resultado Harness debe usar el estilo objetivo aprobado.
- Si la licencia no permite adaptación, se conserva únicamente como referencia y no se distribuye como asset Harness.
- No se completa un hueco visual inventando una identidad biológica.

## Criterio de aceptación

Una escena de muestra en Blender contiene todos los elementos mínimos, mantiene el contrato C0 y ha pasado una revisión visual explícita.
